## Method notes

- Time is counted in **working days** throughout, Sundays and the eight gazetted holidays in the window
  being excluded, because that is the unit the Contract defines.
- No allowance is taken for loss of productivity, disruption or concurrency; only events identifiable in
  the project record are used, and no day is counted twice.
- Every date, amount and event in the report is traceable to a document in Annexure A.
